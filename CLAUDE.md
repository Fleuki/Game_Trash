# CLAUDE.md — как работать в этом репозитории

## Источники истины
- [docs/GDD.md](docs/GDD.md) — что за игра и почему она такая. При противоречии прав GDD.
- [docs/PLAN.md](docs/PLAN.md) — срезы S0–S24, архитектура, критерии готовности, сроки.

Оба читаются в начале сессии, до первой правки. По своей инициативе не переписываются.

## Порядок работы в сессии
1. **Один срез за сессию.** Срез не начинается, пока предыдущий не закрыт (PLAN §0).
2. **Сначала план на утверждение:** что делаю, какие файлы трогаю, критерий готовности из PLAN §4.
3. **Код — только после явного «да».** Нет утверждения — нет ни одной строки кода.
4. В конце — что сделано, что не сделано, что проверить руками.

## Не забегать вперёд
- Ничего из будущих срезов. Ни «заодно», ни «пригодится потом», ни заглушек на будущее.
- Список «снаружи MVP» (GDD §14) не трогается никогда: энергия, вода, логистика с грузовиками,
  погода, сотрудники, дерево технологий, сюжет, экология как система, многоэтажность,
  мультиплеер, достижения сверх минимума. **Если это кажется логичным — тем более нет.**
- Новая сущность, материал или машина — только если она есть в GDD и нужна текущему срезу.
- Числа баланса до появления `docs/economy.md` — черновые. Не «уточнять» их самовольно.
- Увидел нужное, но не из этого среза — сказать словами, не кодом.

## Пять правил архитектуры (PLAN §3.3) — нерушимо
1. **`sim/` не импортирует `render/`, `ui/`, `platform/`.** Нарушил — сборка красная.
2. **Фиксированный шаг 60 Гц.** Ускорение времени = N шагов симуляции за кадр,
   **не** умножение `dt`.
3. **Никакого `Math.random()` в `sim/`** — только `world.rng`, сид пишется в сейв.
4. **Изменения состояния только командами**, применяются на границе тика.
   Никаких прямых мутаций из обработчиков ввода.
5. **Ни одного числа баланса в коде систем** — всё через `config/`.

## Definition of Done для среза (PLAN §12)
- [ ] Запускается, щупается руками, критерий готовности выполнен буквально
- [ ] Все числа — в `config/`, ни одного магического литерала в `sim/`
- [ ] `sim/` не импортирует рендер, DOM и платформу
- [ ] Прогон с одним сидом даёт одинаковый хэш
- [ ] Код прочитан целиком, каждая функция объяснима
- [ ] Нет `TODO` внутри `sim/` — либо сделано, либо выписано в план

## Структура каталогов (PLAN §3.2)
```
src/
  sim/       types world step rng          # чистая логика: не знает про Pixi, DOM, время ОС
    systems/ transport machines contamination economy dayCycle waste
  config/    materials machines districts contracts balance     # весь баланс, только здесь
  commands/  types (union команд)  dispatch (валидация, очередь)
  render/    app gridLayer itemLayer machineLayer fx   # читает WorldState, не пишет в него
  ui/        DOM-панели поверх canvas, не Pixi
  platform/  save (сериализация WorldState)  yandex (SDK за интерфейсом)
  main.ts    склейка: цикл, ввод, рендер
tools/
  headless.ts  прогон N дней без рендера -> CSV
```
Новых каталогов верхнего уровня не заводить. Файл не ложится в структуру — сначала спросить.
