# Вторсырьё

Менеджмент в реальном времени с паузой: мусороперерабатывающий завод, где поток отходов
идёт всегда, а ты строишь и перенастраиваешь сортировочные линии, чтобы вытащить из грязи
как можно больше чистого сырья.

**Платформы:** Яндекс Игры (основная), позже Steam через Tauri
**Стек:** TypeScript + Vite + PixiJS
**Статус:** неделя 0 — баланс в таблице, кода ещё нет
